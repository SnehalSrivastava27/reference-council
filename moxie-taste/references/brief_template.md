## Rules for the brief itself

- Never specify a bathroom by default
- Always two locations, one brighter for the reveal
- Always state where the hair light comes from — a brief without this is incomplete
- Always specify the outfit change
- Pacing as a number, not an adjective
- Hook written, not described
- Maximum three Moxie reference reels

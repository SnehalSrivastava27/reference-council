# Moxie Reference Library

The 15 reference films indexed for pairing. In stage 4 you match each
shortlisted creator reel to the Moxie film it most rhymes with, so the creator
can watch both back to back and see the overlap themselves.

## Matching rule

Match on **the strength you praised**, not on topic. If you shortlisted her reel
for its doorway lighting, pair it with the Moxie film that uses doorway
lighting — even if hers was about skincare and the Moxie one is about hair.

The creator is being shown *"this thing you already do, we do it too."* Topic
similarity is the least useful axis.

## The library

The **Reel URL** column is what the brief emitter reads to fill each reference's
`igUrl` so the portal links straight to the actual reel (a full
`https://www.instagram.com/reel/<shortcode>/` URL, or just the bare `<shortcode>`).
Leave it blank and the emitter falls back to the creator's profile URL. `Video-*`
films are internal Moxie shoots with no public reel and stay blank.

## Pairing by parameter

**Praised her background?**
- Doorway depth → `shrijajhinkwan`
- Workplace as proof → `Video-60764` or `Video-65320`
- Outdoor/travel → `eshnakutty`, `taneesho`
- Soft wall done well → `aashiadani`

**Praised her lighting?**
- Backlight through hair → `eshnakutty`, `taneesho`
- Warm evening practicals → `nutellaonella`
- Consistent soft window → `aashiadani` (lowest variance in the set)

**Praised her pacing?**
- Sub-second demo cutting → `globalbeautyfinds`, `Video-60764`
- Slow narrative that holds → `ahillyeah`
- Accelerate-then-brake rhythm → `aashiadani`, `shrijajhinkwan`

**Praised her hook?**
- Contradiction → `aashiadani`
- Grievance list → `ahillyeah`
- Wager → `Video-65320`
- Flat assertion → `srish_teee`
- Binary question → `vibhasree_`

**Praised her outfit or styling?**
- Solid pastel against pastel wall → `aashiadani`
- Reveal-change into an occasion outfit → `taneesho`
- Uniform as credibility → `Video-60764`

## What to send

Send **one** Moxie reference per shortlisted reel — three max per brief. More
than that and the creator starts copying rather than recognising, which produces
the template convergence this whole standard exists to prevent.
